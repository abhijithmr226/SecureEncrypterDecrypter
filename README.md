A lightweight and user-friendly web application to securely **encrypt and decrypt text**. Designed using modern web technologies, this tool provides a seamless and secure experience across all devices.

---

## 🌟 Features

- 🔒 **Secure Text Encryption**  
  Encode text using reliable encryption logic.

- ⚡ **Instant Decryption**  
  Decode encrypted messages instantly with one click.

- 🧑‍💻 **User-Friendly Interface**  
  Minimal, clean, and intuitive UI for a great user experience.

- 📱 **Cross-Platform Compatibility**  
  Fully responsive design — works smoothly on desktops, tablets, and mobile devices.

## 📌 How to Use

1. Open the [Live Demo](https://tinyurl.com/abhisencrypter-decrypter).
2. Type your message in the **"Enter text"** field.
3. Click **"Encrypt"** to secure the message.
4. To decode, paste the encrypted string and click **"Decrypt"**.
